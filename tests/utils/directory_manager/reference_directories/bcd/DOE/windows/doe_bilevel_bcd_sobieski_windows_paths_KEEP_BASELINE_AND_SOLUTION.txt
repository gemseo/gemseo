# This is the path structure for a BiLevel BCD Sobieski Scenario.
# The system level scenario uses the LHS algorithm with an n_samples set to 3.

# The BCD MDA is an MDAGaussSeidel with a max_mda_iter set to 2.
# The 3 sub scenarios use SLSQP as the optimization algorithm with a max_iter set to 5.
# Each of the sub scenarios uses an MDF formulation solved with an MDAGaussSeidel, the max_mda_iter is set to 2 for all of them.
# The overall execution chain of the scenario is System Scenario -> MDA1 -> BCD MDA(Subscenarios(MDA(Structure, Aero, Propulsion, Mission))) -> MDA2
