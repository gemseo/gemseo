`MDOObjectiveScenarioAdapter` was removed; use `MDOScenarioAdapter` with `output_optimal_objective=True`, which reports the optimal value of the objective recorded by the scenario instead of the value computed by its disciplines at the optimal design point. The codemod rewrites the class name but cannot add the argument, so the gemseo 6 import path raises an `ImportError` naming the replacement instead of resolving to an adapter reporting a different objective value.
