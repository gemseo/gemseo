- `Discipline._compute_jacobian` receives the names of the inputs and outputs without namespace prefix and must set `jac` with these names, as `_run` does with its input and output data.
  `Discipline.linearize` adds the namespace prefixes afterwards.
  A discipline that prefixed the names of its Jacobian by itself must no longer do so.
  The process disciplines, i.e. the chains, the MDAs and the scenario adapters, keep working with the namespaced names of their sub-disciplines.
- A wrapper discipline that calls the `_compute_jacobian` of its wrapped discipline with namespaced names must call `_compute_jacobian_with_namespaces` instead, as `RemappingDiscipline` and `FilteringDiscipline` do.
- `ConstraintAggregation` aggregates each constraint into its own output; it used to aggregate all the constraints into the first output and to set the other outputs to empty arrays. The options `indices` and `scale` refer to the components of each constraint.
- `Concatenater` raises a `ValueError` when an input name is repeated at instantiation; it used to ignore the repetition. `LinearDiscipline` raises a `ValueError` when an input name or an output name is repeated at instantiation; it used to fail at execution.
