A `RemappingDiscipline` no longer silently truncates a remapped value to fit the type of the default value of the wrapped discipline: an array variable remapped as a whole is passed without cast, and a value remapped to some components of an array variable raises a `ValueError` when it cannot be stored in this variable without loss of information, e.g. a float in an integer variable, a string longer than the strings of the variable or a float overflowing a variable of lower precision; rounding a float to a lower precision is accepted.
