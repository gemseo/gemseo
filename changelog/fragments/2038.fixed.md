- A discipline with a path input or output can now use `HDF5Cache` and `MemoryFullCache`; see [Path variables][concept-cache-path-variables] for the details.
- `BaseDataConverter.get_value_size` returns 1 for a path value, as for a `str`, instead of raising a `TypeError`.
- `compare_dict_of_arrays` returns `False` when a string array is compared to an array of numbers with a tolerance, instead of raising an error.
- `BaseDataConverter.convert_data_to_array` raises a `TypeError` when the values of some data are strings or paths and those of others are numbers, instead of returning a string array.
