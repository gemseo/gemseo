- `DesignSpace.to_csv` raises a `ValueError` naming the unknown `fields` instead of a pandas `KeyError`, reads a string `fields` as one field, and writes the `type` column whenever a variable is not real.
- `DesignSpace.from_csv` reads files with a single row, an iterator or string `header`, padded cells, an empty `None` value and an empty type, reads a file without variable as an empty design space, and raises a `ValueError` naming the file, and the cells that are not numbers, when it is malformed.
