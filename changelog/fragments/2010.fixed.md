- `ArrayBasedFunctionDiscipline` and `LinearDiscipline` concatenate their input values in the order of the input names passed at instantiation, including when executed with default input values set in another order and when some inputs have a namespace.
- `ArrayBasedFunctionDiscipline` no longer raises a `KeyError` when computing its Jacobian with namespaced variables, and `LinearDiscipline` no longer raises a `KeyError` when computing its outputs or its Jacobian with namespaced variables.
- `Concatenater` concatenates its input values in the order of the input names passed at instantiation when some inputs have a namespace, and no longer raises a `KeyError` when computing its Jacobian with namespaced variables.
- `LinearCombination` no longer raises a `KeyError` when computing its Jacobian with namespaced variables.
- `AnalyticDiscipline` no longer computes a zero derivative with respect to a namespaced input and no longer raises a `KeyError` when computing its Jacobian with a namespaced output.
- `ConstraintAggregation` no longer raises a `TypeError` when computing its Jacobian with the `MAX` aggregation function.
- The Jacobian of the maximum used by `ConstraintAggregation` and by the aggregation of constraints with `MAX` is correct with an array `scale`; each derivative used to be multiplied by the scale of another constraint.
- `ArrayBasedFunctionDiscipline` computes its Jacobian correctly when a name is both an input and an output with different sizes.
- `RemappingDiscipline` no longer raises a `KeyError` when executed or linearized with a namespace on its own variables.
- `FilteringDiscipline` and `RetryDiscipline` pass the input values to a wrapped discipline with namespaces; the wrapped discipline used to receive the names without namespace prefix and to use its default input values instead.
- `FilteringDiscipline` no longer raises a `KeyError` when executed or linearized with a namespace added on its own variables.
- `JobSchedulerDiscipline` passes the input values to the wrapped discipline when a namespace is added on its own variables; the wrapped discipline used to use its default input values instead.
- `JobSchedulerDiscipline` can be linearized when the wrapped discipline has namespaces; the job used to fail.
- `JobSchedulerDiscipline` no longer raises a `ValueError` when linearized over a subset of the namespaced variables, and raises a `KeyError` when the Jacobian of the wrapped discipline has names that are not its variables; the Jacobian names used to be renamed without being checked.
- `Discipline.linearize` no longer raises a `KeyError` with a hybrid approximation mode when the discipline computes all the derivatives of an output analytically.
- `AutoPyDiscipline` can be linearized several times with input values of different sizes; it used to raise a `ValueError` about the shape of the Jacobian from the second size.
