BREAKING CHANGE: The `gemseo.settings` aggregator package was removed; the settings classes are now re-exported by their domain packages, e.g. `from gemseo.optimization import SLSQP_Settings`. Mapping: `gemseo.settings.opt` → `gemseo.optimization`, `gemseo.settings.doe` → `gemseo.doe`, `gemseo.settings.mda` → `gemseo.mda`, `gemseo.settings.post` → `gemseo.post`, `gemseo.settings.formulations` → `gemseo.formulation`, `gemseo.settings.linear_solvers` → `gemseo.linear`, `gemseo.settings.ode` → `gemseo.ode`, `gemseo.settings.mlearning` → `gemseo.machine_learning`, `gemseo.settings.probability_distributions` → `gemseo.uncertainty.distribution` and `gemseo.settings.base_settings` → `gemseo.util.pydantic`.
