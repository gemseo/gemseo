- [generate_coupling_graph()][gemseo.generate_coupling_graph], [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph] and [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] return a `graphviz.Digraph` instead of a `GraphView`; use its `render()` method instead of `visualize()`, e.g. `graph.render(outfile="graph.pdf", view=True)`, and `graph.node(name, style="invis")` instead of `hide_node(name)`.
- The DOT source file kept by [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] with `clean_up=False` has the `.gv` extension instead of `.dot`, e.g. `graph.gv` for `file_path="graph.pdf"`, unless `file_path` has the extension `.gv`.
- The nodes of the graph returned by [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] are named `"d<i>"` for the discipline at position `i`, `"scc<i>"` for a group of strongly coupled disciplines of the condensed graph and `"h<i>"` for a hidden node, instead of the name of the discipline, `"MDA of <discipline names>"` and `"_<name>"` or `"_<i>"`; use these node names to style the graph, e.g. `graph.node("d0", fillcolor="red")`, as described in [draw_coupling_graph()][gemseo.post.graph.draw_coupling_graph]. The nodes of this graph are filled in white by default (`node [fillcolor=white style=filled]`) and its edges no longer have the attributes `color=black`, `dir=forward`, `fontcolor=black` and `penwidth=1.0`, which are the Graphviz default values.
- [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] raise a `ValueError` for a file path with the extension `.gtk`, `.x11` or `.xlib`, whose Graphviz formats open a window instead of saving the graph to a file; to open such a window, pass an empty file path and call the `render()` method of the returned graph with this format, e.g. `generate_coupling_graph(disciplines, "").render(format="x11", cleanup=True)`.
