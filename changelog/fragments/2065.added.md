- [draw_coupling_graph()][gemseo.post.graph.draw_coupling_graph] draws the coupling graph of a [DependencyGraph][gemseo.core.dependency_graph.DependencyGraph], either full or condensed, as a [graphviz.Digraph](https://graphviz.readthedocs.io/en/stable/api.html#graphviz.Digraph) without saving it (its `render()` method saves or shows it); its `get_edges` argument draws and styles one edge per coupling variable, or per element of a returned list, e.g. one per component; its `input_names` and `output_names` arguments draw the inputs and outputs of the problem as source and sink nodes, styled with `get_node_attributes`.
- [save_graph()][gemseo.post.graph.save_graph] saves a Graphviz graph, i.e. a [graphviz.Graph](https://graphviz.readthedocs.io/en/stable/api.html#graphviz.Graph) or a [graphviz.Digraph](https://graphviz.readthedocs.io/en/stable/api.html#graphviz.Digraph), e.g. drawn by [draw_coupling_graph()][gemseo.post.graph.draw_coupling_graph], to a file whose extension sets the format, e.g. `graph.pdf`, removing the DOT source file or keeping it with the extension `.gv` (`.dot` for a `.gv` file), without changing the graph.
- [DependencyGraph][gemseo.core.dependency_graph.DependencyGraph] has the new method `create_condensed_graph()`.
