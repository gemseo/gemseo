`DesignSpace.add_catalog_variable` adds a catalog variable,
a categorical variable choosing one alternative in a `gemseo.space.Catalog`,
a table with one row per alternative, one column per property
and one distinct label per alternative;
see [catalog variables][concept-catalog-variables].
It comes with `gemseo.space.variable.CatalogVariable`,
which shares `gemseo.space.variable.BaseCategoricalVariable` with `CategoricalVariable`,
`VariableType.CATALOG` and `DriverDescription.handle_catalog_variables`;
no GEMSEO driver handles such a variable yet.
