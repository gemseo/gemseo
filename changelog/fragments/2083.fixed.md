`HDF5Cache` can be used with multiprocessing, including on Windows,
e.g. when a DOE evaluates a discipline with several processes.
Two processes used to write their entries at the same indices,
as a cache counts its entries in a counter of its own process,
so that all the writes but one failed;
the index of a new entry is now allocated from the file.
The HDF5 file is also closed whatever happens while it is read,
as a file left open prevented another process from opening it.
