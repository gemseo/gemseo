- The post-processing methods of the sensitivity analyses no longer crash on an output component of zero variance, whose sensitivity indices are undefined.
- `plot()`, `plot_comparison()`, `plot_field()` and `sort_input_variables()` of the sensitivity analyses raise a `ValueError` saying that the sensitivity indices are undefined when the output component is constant.
- `sort_input_variables()` of the sensitivity analyses, `CorrelationAnalysis.plot()`, `MorrisAnalysis.plot()`, and `plot()` and `plot_second_order()` of `SobolAnalysis` and `ROSobolAnalysis` use the first non-constant component of an output given by its name, instead of its first component.
- `plot_comparison()` of the sensitivity analyses uses the first component of an output given by its name that is non-constant for all the compared analyses, instead of its first component.
- The methods of the sensitivity analyses taking an output, e.g. `sort_input_variables()`, `plot()`, `plot_bar()`, `plot_radar()`, `plot_field()` and `plot_comparison()`, raise a `ValueError` naming the output, or the output component, that does not exist, instead of a `KeyError` or an `IndexError`, and `plot_comparison()` also names the analysis, current or compared, that does not have it or whose output component is constant.
- `plot_bar()` and `plot_radar()` of the sensitivity analyses leave out the constant output components; a `sorting_output` given by its name uses the first non-constant component of this output among the plotted ones and a `sorting_output` that is not among the plotted outputs raises a `ValueError`.
- `plot_bar()` and `plot_radar()` of the sensitivity analyses plot once an output component given several times in `outputs`, instead of raising a `ValueError`.
- `plot_field()` of the sensitivity analyses shows the constant output components as gaps, including over a 2D mesh, and, when the output is given by its name, sorts the inputs according to its first non-constant component.
- `plot_field()` of the sensitivity analyses no longer raises a `ValueError` when the inputs have different sizes.
- `plot_field()` of the sensitivity analyses raises a `ValueError` naming the inputs when none of `input_names` is an input, instead of an `IndexError`.
- `SobolAnalysis.plot()` and `ROSobolAnalysis.plot()` rank last an input whose Sobol' indices are `nan`, instead of placing it anywhere.
- `HSICAnalysis.filter()` returns `None` for a constant output component.
- `HSICAnalysis.filter()` no longer raises a `ValueError` for an input with several components.
- `to_dataset()` of the sensitivity analyses stores `nan` for a constant output component and `standardize_indices()` leaves its undefined indices (`None`) as they are.
- The matplotlib version of the `Surfaces` dataset plot leaves out the triangles of the mesh with a non-finite value, which show as a gap, instead of raising a `ValueError`.
- The `Surfaces` dataset plot titles each selected sample with its own name, instead of the name of another sample.
