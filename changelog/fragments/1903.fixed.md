- `RemappingDiscipline` no longer requires a default value for every input variable of the wrapped discipline; only the input variables mapped component-wise, e.g. `{"x": ("a", 0)}`, need one.
- Values that are not NumPy arrays, e.g. floats handled by an `AutoPyDiscipline`, are supported.
- Name mappings that refer to an unknown variable of the wrapped discipline or rename an original variable as a whole more than once are now rejected.
