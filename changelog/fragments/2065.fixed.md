- [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] with `full=False` no longer raise an `AttributeError` when several disciplines have the same name, and draw one node per discipline.
- [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] no longer merge the edges of the outputs of several leaf disciplines having the same name, and now show the tooltips of the coupling variables when several disciplines have the same name.
- [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] now draw a discipline whose name contains a `":"` as a single node, and no longer hide a discipline whose name is that of a leaf discipline prefixed by `"_"`.
- [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] now list the variables of the tooltip of an edge in alphabetical order, like its label, instead of an order that could change from one run to another.
- [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] can save the graph to a file with the `.dot` extension instead of raising a `ValueError`.
- [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] with `clean_up=True` no longer overwrite and remove the file next to the output file named like the DOT source file, e.g. `graph.dot` for `file_path="graph.pdf"`.
- [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] now draw a discipline without outputs whose inputs are not computed by another discipline, which was missing from the graph unless several disciplines had the same name.
- The `copy()` and `subgraph()` methods of the graph returned by [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] no longer raise a `TypeError`.
- [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] with `file_path=Path("")` no longer raise a `ValueError` and, like with `file_path=""`, do not save the graph.
- [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] now display the name of a discipline or coupling variable starting with `"<"` and ending with `">"`, e.g. `"<A>"`, as is instead of as an HTML-like label, which removed the angle brackets or could make the graph fail to save.
- [DependencyGraph.render_full_graph()][gemseo.core.dependency_graph.DependencyGraph.render_full_graph], [DependencyGraph.render_condensed_graph()][gemseo.core.dependency_graph.DependencyGraph.render_condensed_graph] and [generate_coupling_graph()][gemseo.generate_coupling_graph] can save the graph in the Graphviz formats `xdot1.2` and `xdot1.4`, e.g. `graph.xdot1.4`, instead of raising an error.
